# Channel3 GDrive Privacy Policy

**Effective date: September 24, 2026**

This Privacy Policy explains how **Channel3 GDrive** accesses, uses, stores, retains, and shares Google user data. Channel3 GDrive is a private automation application operated by its owner to manage project files in an authorized Google Drive account.

## Google user data accessed

When the owner authorizes Channel3 GDrive, the application may access Google Drive data available to that authorized account, including:

- file and folder names, IDs, metadata, and hierarchy;
- file contents for project artifacts that the workflow needs to upload, download, or verify; and
- information needed to create folders and manage files for the owner's Channel3 projects.

Channel3 GDrive does not intentionally access Google user data for purposes unrelated to these file-management functions.

## How Google user data is used

Google Drive data is used only to provide the application's owner-facing production features:

- list and locate project files and folders;
- create project directories;
- upload project artifacts;
- download project artifacts; and
- read files back and compare file hashes or metadata to verify successful storage.

Google user data is **not** used for advertising, retargeting, personalized marketing, credit-worthiness decisions, lending, data brokerage, or the creation of unrelated user profiles.

## Data storage and security

OAuth credentials used by Channel3 GDrive are stored on a private server controlled by the application owner and are not committed to the public website repository.

Project artifacts and relevant file metadata may be stored or cached on that private server when needed for the production workflow, including before upload and during download/readback verification.

Reasonable technical and operational measures are used to protect credentials and project data against unauthorized access, alteration, disclosure, or destruction.

## Data sharing and transfer

Channel3 GDrive does not sell Google user data and does not share Google user data with advertising platforms, data brokers, or other third parties for marketing or commercial profiling.

Google user data is not transferred to third parties except where necessary to provide the authorized user-facing functionality, for security purposes, to comply with applicable law, or otherwise as permitted by the Google API Services User Data Policy and with any required user consent.

Human access to Google user data is limited to the application owner, except where access is necessary for security, legal compliance, or another purpose expressly permitted by Google's policies.

## Data retention and deletion

Project files and metadata are retained only for as long as needed for the owner's production workflow or backup requirements.

The owner can delete project artifacts from the private server and Google Drive at any time. Google Drive authorization can also be revoked at any time from the Google Account's connected-app permissions. Revoking authorization prevents Channel3 GDrive from obtaining new access tokens for that account.

## Limited Use

Channel3 GDrive's use and transfer of information received from Google APIs adheres to the **Google API Services User Data Policy**, including the **Limited Use** requirements.

The application limits its use of Google user data to the owner-facing file-management and integrity-verification features described on this page.

## Changes to this policy

If Channel3 GDrive changes the way it accesses, uses, stores, or shares Google user data, this Privacy Policy will be updated before the new data use is introduced where required, and additional consent will be obtained when applicable.
