# Channel3 GDrive

**Channel3 GDrive** is a private automation application used by its owner to manage production project files in an authorized Google Drive account.

## What the application does

Channel3 GDrive supports the file operations required by the owner's Channel3 production workflow, including:

- listing and locating authorized Google Drive files and folders;
- creating project folders;
- uploading project artifacts;
- downloading project artifacts; and
- reading files back to verify file integrity after upload.

## Why Google Drive access is requested

Google Drive access is requested only so Channel3 GDrive can perform the file-management actions above on behalf of the authorized account owner. The application does not use Google Drive data for advertising, profiling, credit decisions, data brokerage, or unrelated analytics.

Channel3 GDrive is not offered as a public SaaS service. It is an owner-operated automation tool for the owner's own production workflow.

## Privacy

For details about how Google user data is accessed, used, stored, retained, and shared, read the **[Channel3 GDrive Privacy Policy](https://techai8.com/channel3/privacy/)**.

Access to Google Drive can be revoked at any time from the authorized Google Account's connected-app permissions.
